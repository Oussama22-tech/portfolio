A neuron is linear regression in disguise

A single Dense unit with no activation computes exactly w·x + b. Setting its weights by hand and comparing against NumPy proves it.

C2_W1_Lab01_Neurons_and_Layers.ipynbpython
# One Dense unit, no activation:  f(x) = w·x + b
linear_layer = tf.keras.layers.Dense(units=1, activation='linear')
linear_layer(X_train[0].reshape(1, 1))          # first call builds the weights

set_w = np.array([[200]])
set_b = np.array([100])
linear_layer.set_weights([set_w, set_b])

a1   = linear_layer(X_train[0].reshape(1, 1))           # TensorFlow
alin = np.dot(set_w, X_train[0].reshape(1, 1)) + set_b  # NumPy
# identical outputs -> the layer IS the regression model

Why it matters: adding a sigmoid to the same unit turns it into logistic regression. Neural networks are stacks of models I already understood.

Softmax, and the numerically stable way to train with it

Softmax written from scratch, then the preferred multiclass setup: a linear output layer with the softmax folded into the loss.

C2_W2_SoftMax.ipynbpython
def my_softmax(z):
    ez = np.exp(z)             # element-wise exponential
    return ez / np.sum(ez)     # each output in (0, 1), all sum to 1

# Preferred: linear outputs ("logits") + from_logits=True
preferred_model = Sequential([
    Dense(25, activation='relu'),
    Dense(15, activation='relu'),
    Dense(4,  activation='linear'),
])
preferred_model.compile(
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    optimizer=tf.keras.optimizers.Adam(0.001),
)

logits   = preferred_model.predict(X_train)
probs    = tf.nn.softmax(logits).numpy()   # only when probabilities are needed
category = np.argmax(logits, axis=1)       # argmax works directly on logits

Why it matters: computing softmax inside the loss avoids round-off error, the same reasoning behind careful numerics in circuit simulation.

Looking inside the network: ReLU features

A 4-class classifier with only 2 ReLU units, then pulling out the trained weights to see what the hidden layer computes.

C2_W2_Multiclass_TF.ipynbpython
model = Sequential([
    Dense(2, activation='relu',   name='L1'),
    Dense(4, activation='linear', name='L2'),
])
model.compile(
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    optimizer=tf.keras.optimizers.Adam(0.01),
)
model.fit(X_train, y_train, epochs=200)

# What did the hidden layer learn?
W1, b1 = model.get_layer('L1').get_weights()
Xl2 = np.maximum(0, np.dot(X_train, W1) + b1)   # ReLU = max(0, z)
# Xl2 are the "new features" the output layer actually sees

Why it matters: ReLU's "off" region lets each unit cut the input space along one line, so units combine like piecewise-linear segments instead of interfering.

Choosing a decision-tree split by information gain

Entropy measures how mixed a node is; the best split is the feature that reduces it the most.

C2_W4_Lab_01_Decision_Trees.ipynbpython
def entropy(p):
    if p == 0 or p == 1:
        return 0
    return -p * np.log2(p) - (1 - p) * np.log2(1 - p)

def information_gain(X, y, left_indices, right_indices):
    h_node  = entropy(sum(y) / len(y))
    w_left  = len(left_indices)  / len(X)
    w_right = len(right_indices) / len(X)
    p_left  = sum(y[left_indices])  / len(left_indices)
    p_right = sum(y[right_indices]) / len(right_indices)
    return h_node - (w_left * entropy(p_left) + w_right * entropy(p_right))

for i, name in enumerate(['Ear Shape', 'Face Shape', 'Whiskers']):
    left, right = split_indices(X_train, i)
    print(f"{name}: {information_gain(X_train, y_train, left, right):.2f}")

Why it matters: the tree is built by repeating this choice recursively until a stopping rule (max depth, pure node, or too little gain) is met.
